# 什么是 Win PE

WinPE (Windows Preinstallation Environment)，即 Windows 预安装环境，是微软开发的一个轻量级、小型化的操作系统。它主要用于安装、部署和修复Windows 桌面版、Windows Server 等操作系统。

你可以把它理解为一个功能精简但拥有极高系统权限（以System账户登录）的“超级精简版”Windows。它通常被制作在U盘、光盘等便携设备中，通过加载到电脑内存中运行，因此可以不依赖硬盘启动。


主要用途和功能
WinPE 是一个强大的维护工具，主要用途包括：

系统部署与安装：这是它最初的设计目的，用于在电脑上全新安装Windows系统。它可以在安装前对硬盘进行分区和格式化，并支持从网络或本地驱动器复制和部署系统映像。

系统维护与修复：当你的主操作系统无法启动时，可以通过WinPE启动电脑，进行故障排查和修复。例如，修复启动记录、还原系统等。

数据恢复：在系统无法进入的情况下，你可以使用WinPE来访问硬盘，并抢救其中的重要数据。

高级磁盘操作：WinPE提供了DiskPart等命令行工具，可以进行高级的磁盘管理操作。

关键特性与局限
特性：

硬件要求低：基本版本仅需512MB内存即可运行，甚至不需要硬盘。

支持网络：支持通过TCP/IP连接网络文件服务器。

支持脚本：支持批处理文件、PowerShell等脚本，便于自动化操作。

内置工具：包含DISM（部署映像服务和管理）、DiskPart等核心部署和维护工具。

局限：

功能有限：它是一个“有限服务”的最小Win32子系统，并非完整的Windows，不能作为日常使用的操作系统。

不是通用系统：微软明确表示，它不应被用作硬件验证、瘦客户端或嵌入式操作系统。

如何获取和使用
WinPE 并非独立销售的产品。它作为 Windows 评估和部署工具包 (Windows ADK) 的一个附加组件，可以免费获取。你可以从微软官网下载并安装ADK及WinPE附加组件来创建自己的WinPE启动盘。
